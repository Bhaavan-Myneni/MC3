📱 Generate QR Code

Create a QR code for your MC3 Summit 2025 website

⚠️ Important: Your website must be deployed online first (using Netlify, GitHub Pages, or Vercel) to get a public URL. Local URLs (like localhost:8000) won't work for others to scan.

📋 How to Use:

  1. Deploy your website first using Netlify Drop, GitHub Pages, or Vercel
  2. Copy your website URL (e.g., https://your-site.netlify.app)
  3. Paste the URL in the field above
  4. Click "Generate QR Code"
  5. Download the QR code and share it with others
  6. Print or share the QR code - when scanned, it will open your website!
Example URLs:
• https://mc3-summit-2025.netlify.app
• https://yourusername.github.io/mc3-summit-2025/
• https://mc3-summit-2025.vercel.app
