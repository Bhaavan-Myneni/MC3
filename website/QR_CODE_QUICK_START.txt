========================================
📱 QUICK START: Generate QR Code
========================================

⚠️ IMPORTANT: Deploy your website first!
Your website must be online (not localhost) for the QR code to work.

========================================
METHOD 1: Web Interface (EASIEST) ⭐
========================================
✅ No installation needed
✅ Works immediately
✅ Visual interface

STEPS:
1. Deploy your website (use Netlify Drop - see DEPLOY_NOW.md)
2. Get your website URL (e.g., https://your-site.netlify.app)
3. Double-click: generate-qr.html
4. Paste your URL in the input field
5. Click "Generate QR Code"
6. Download the QR code image
7. Share or print it!

That's it! People can now scan the QR code to access your website.

========================================
METHOD 2: Python Script
========================================
Requires: Python + qrcode library

INSTALLATION:
1. Install Python (if not installed): https://www.python.org/
2. Install library: pip install qrcode[pil]
3. Run: python generate_qr_code.py https://your-website.netlify.app

Or use the batch file: generate-qr.bat

========================================
RECOMMENDED: Use Method 1 (Web Interface)
It's the fastest and requires no setup!
